Qué incluye y qué no cada rango

Regla editorial del hub: sin alcance definido un precio no significa nada.

Landing / web corporativa

+/-

Sitio de 5–8 páginas con CMS simple y SEO base.

Incluye

  • Diseño responsive (5–8 secciones)
  • CMS simple para editar textos
  • SEO técnico base + meta tags
  • Formularios de contacto
  • Entrega de código y deploy

No incluye

  • ·Copywriting profesional
  • ·Integraciones complejas (pagos, ERP)
  • ·Mantenimiento anual
  • ·Hosting del año 1

CRM / ERP a medida

+/-

Web app con 2–4 módulos de gestión de operaciones.

Incluye

  • 2–4 módulos (clientes, inventario, ventas, reportes)
  • Autenticación y roles de usuario
  • Base de datos y panel admin
  • Despliegue y capacitación básica
  • Garantía inicial (30 días)

No incluye

  • ·Personalizaciones fuera de alcance
  • ·Migración de datos heredados compleja
  • ·Licencias de software de terceros
  • ·Mantenimiento mensual

Preguntas frecuentes sobre precios

¿Estos precios son una cotización?

No. Son benchmarks de mercado para LATAM (USD), validados contra Clutch.co, Glassdoor y directorios locales. Un proyecto real puede variar según el alcance, el equipo y los plazos. La cotización detallada siempre es con alcance definido.

¿Por qué una agencia cobra 1.8–2.5x la hora de un freelance?

Porque el precio de agencia incluye QA, Project Manager, diseño UX/UI, gestión de cuenta y garantía. Comparar 'hora de agencia' con 'hora de freelance' sin considerar eso no sirve para estimar presupuestos.

¿Cuánto cuesta mantener el software después de entregarlo?

Entre el 10% y el 15% del costo del proyecto por año. No es opcional: las aplicaciones sin mantenimiento acumulan vulnerabilidades, dependencias rotas y bugs hasta quedarse obsoletas.

¿De dónde salen los datos del hub?

De rangos de tarifas publicados, cotizaciones de proyectos propios de Rsolitario (50+ proyectos) y directorios de empleo locales como Computrabajo o Bumeran. Se recalibran cada 6 meses.

¿Qué incluye exactamente cada rango de precio?

Cada tipo de proyecto tiene columnas 'Incluye' y 'No incluye' para que compares manzanas con manzanas. Regla editorial: ningún precio se publica sin alcance, plazo y equipos involucrados.
